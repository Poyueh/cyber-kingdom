# 製作進度

目前試玩：F5 → REFUGE / 避難所 → 隨機邊境。最新內容為採集、生產、擴建、守城與本輪王國目標，詳見本文最後一節；前段保留歷次開發紀錄。

## 方向與時程

採用 Godot，目標 iPhone / iPad。六個月是製作目標，不是上架、收益或所有內容完成的保證；優先用小型可玩版本驗證。先驗證市場，再定財務目標。

| 月份 | 可驗證成果 |
| --- | --- |
| 第 1 月 | 戰鬥與營地各一個小型原型、觸控實機試玩、確認核心玩法 |
| 第 2 月 | 結合成 10–15 分鐘循環，建立原創像素美術規格 |
| 第 3 月 | 義肢改裝、關卡變化、少量敵人與一次首領戰 |
| 第 4 月 | 內容製作、平衡、存檔與裝置效能；小規模外部測試 |
| 第 5 月 | TestFlight 測試、商店素材、短影片與低成本行銷實驗 |
| 第 6 月 | 修正、發行準備、定價與上架驗證；依測試結果縮減範圍 |

每月以實際試玩結果調整，避免先做大量關卡再發現核心不好玩。Apple 帳號、硬體、上架與廣告等成本另計；目前專案不引入付費工具或服務。

夜襲實際從右側進場，有接近與攻擊預警。居民僅在未被防護擋住的命中後失去器具與身分，能再次招攬、補器具就職。騎士可用原有走跳、劈砍與衝刺保護居民。義肢爐與護民塔共用有限龍晶，分別增強騎士或抵擋下一次居民受擊。擊敗敵人產生可拾取廢料，逃離敵人不給獎勵。

預設 14 廢料、3 龍晶、3 名流浪者；55 秒整備後開始三波 3／4／5 名敵人的試煉，波間 30 秒。三波結束保留居民與建築實際狀態，沒有自動宣告所有人獲救。R 重試本輪，Esc／失去焦點暫停。無永久居民／經濟存檔，未改動訓練場存檔；尚未做農業、工坊擴建、工具掉落回收、多側攻城或完整隨機出征。

TDD 先驗證缺少規則與自主模擬的失敗再逐段實作。後續回歸測試抓到倒數被每幀重置、敵人離場誤用近戰停止距離而停在出口前的問題，已根據實際原因修正。新增行為包含招攬與器具只領一次、付款等待工人、升級與修復、受擊再就職、守備反擊、共享龍晶、三波完結與廢料拾取。場景以真實鍵盤與指標事件驗證 E、行走、投入、施工、暫停、重試和 J 傷害夜襲敵人。

## 隨機邊境、採集生產與王國目標（2026-09-10）

F5 → REFUGE / 避難所現在進入 scenes/frontier.tscn；獨立繼承原場景，保留使用者的編輯器修改。兩側六區以種子變動森林、晶脈、遺跡的次序、寬度與資源位置，接近探索揭露。資源總量固定保底；遺跡高台由基本跳躍可達。R 重玩同圖，N／新地圖重置為下一個種子。

新增真實劈砍取得有限木材、龍晶、野果與廢料箱；資源耗盡只結算一次。E 採集會面向目標，超出劍距提示靠近。新增鋤頭／獵弓器具，居民自行就職農夫／獵人；農田須開墾且有工人才產糧留種，獵人走向已探索區域的有限獵物。

木材與食物投入二階城鎮擴建，食物可強化騎士的實際劍傷。義肢爐和護民塔仍共用龍晶；守城回收廢料支撐建設。王國完成要求騎士存活、三波結束、王城三級、二級防線存活且至少三名居民。預設第一次夜襲延到 120 秒，農作週期／淨收量、訓練成本／收益可於 data/frontier.tres 調整。
