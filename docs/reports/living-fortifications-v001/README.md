2026-09-14。功能分支 feature/living-fortifications。

## 行為與場景

`bash tools/check.sh` 完整通過：27 組 Godot 行為／場景測試共 1770 項斷言，零失敗；另含桌面／iOS／Web 打包工具、三語指南與架構檢查。Godot 無 SCRIPT ERROR／ERROR。新增規則先確認失敗，再實作；最後以實際場景的互動按鈕付款、夜間工匠施工、暫停、三級塔與雷射傷害驗證連接。

回歸修正：農夫的強型別工作地點陣列；拓荒站與新隨機建築的付款位置重疊。空地保持較寬間距；尚未投入龍晶的拓荒站會選擇區域內另一個可用位置，已投資或已建的拓荒站不搬移。實際採集／擴建場景亦通過。

真實 v5 紀錄轉換涵蓋旧居民防護、塔等級、受損石牆和修復投入；v6 儲存隨機用途和施工進度。隨機用途不依讀檔重新抽取。
