# Cyber Kingdom 0.0.3 — 龍晶殘影與獨立旅程

[線上試玩](https://poyueh.github.io/cyber-kingdom/)

- 採集、建造與強化統一使用龍晶，保留有限背包和場景掉落。
- 新起始頁：新遊戲、選擇紀錄。每段旅程獨立保存，支援舊版紀錄轉換。
- 龍晶殘影在騎士身旁指引目標；可以自由探索，不必照順序跟隨。
- 騎士、居民和敵人新增受擊反應，護盾受擊與敵人倒下也有不同表現。
- 更新選單內圖文指南，並內附繁體中文字型。

本次附件為 H5 瀏覽器版；Windows／Mac 請沿用 [v0.0.1 下載](https://github.com/Poyueh/cyber-kingdom/releases/tag/v0.0.1)。

網頁紀錄保存在目前瀏覽器與網站中，不會跨裝置同步。仍是開發試玩版，尚未完成實體 iPhone 的效能與多點觸控驗證。

驗證：1178 項規則斷言、場景整合與 13 項 Python 測試通過；另完成實際 Godot 動畫及 H5 新遊戲、紀錄載入與手機橫向版面檢查。
