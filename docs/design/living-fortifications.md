# 城內夜間施工與三階防線

2026-09-14。延續平地探索，保留獵人／弓兵，不新增守備兵。

- 工匠白天承接工作；夜間仍處理完整防線內的城牆、拓荒站、守護塔與農地訂單。起點、終點都必須在現存左右防線內，沿途有敵人則不施工。沒有完整牆的一側只視營地附近為安全範圍；失守即重新檢查並退回。
- 舊護民塔改為自動攻擊塔。三級花費 3／5／8 龍晶，需要聚落 1／2／3 級，由工匠施工。預設箭傷 12、間隔 1.6 秒；連弩傷 12、間隔 0.65 秒；雷射傷 36、間隔 1.1 秒。傷害即時結算，箭矢旅行為視覺回饋。UI 顯示估算每秒傷害。
- 城牆升為木牆 40、石牆 80、堡壘 160 耐久，建造／升級花費 3／4／7。受損先維修，堡壘需三級聚落。
- 新的建築用途由種子固定：符合空間條件的樹木、晶礦和石礦清除後顯示城牆／塔／農地圖示。相鄰障礙清除才顯示，不是每一棵樹都擠一栋建築；用途不隨讀檔或付款變更。
- 新農地花費 3，工匠建成後由農夫白天耕作，沒有農夫不產出。多位農夫分配至現有農地，龍晶留在當地供收取。原有拓荒站和固定外牆仍保留。
- 存檔格式 v6；真實 v5 fixture 覆蓋舊紀錄轉換。已建護民塔轉第一階箭塔，舊居民防護次數、受損牆血量、部分修復投入保留。未知或損壞紀錄不覆蓋。

分層：BuildingSites 管配置與種子用途；FortificationWork 管工匠承接流程；CampaignSession 協調戰役；CampaignView 負責素材、箭與光束。Inspector 可改施工時間、基礎塔傷與基礎射程。
