# 出征圖示引導

目標：熬過首晚後仍看得懂下一步，已支付的遠征能辨識工匠行程、敵人阻擋與封印進度。沿用現場龍晶格和實際材料提示，不新增文字面板或強制流程。

## 判斷

首日交給 CampaignGuide；之後讀取真實裂隙前置條件，提示二級聚落、存活一晚、工匠。晚建營地仍指向首次營火互動，核心受損先充能以恢復原升級選項。夜間及日落前三十秒，尚未出征時建議回防。

背包空找已知可用龍晶、寶箱或交易，否則探索。未知裂隙只給地圖方向，不揭露精確位置。已有遠征訂單優先跟進，先跟已有工匠的訂單，再考慮其他未分配訂單；工匠搬運實際貨物時提示等待交貨，移動途中指向工匠。

騎士離封印範圍過遠或跳得太高時提示靠近；工匠與騎士到位後，有敵人或守門者尚未出場時提示戰鬥。清空才顯示守住位置及真實封印進度。兩側封印後還有敵人則提示清敵，不能提早當勝利。失去工匠要補招募／器具，空背包先找資金，不再為同筆訂單付款。

## 架構

ExpeditionGuide 是 application 層的唯讀查詢；它共用 CampaignSession.rift_requirements／expedition_status，和真正解鎖、守門者生成及封印判定使用相同條件。生成守門者之後必須重新查 contested，避免新敵人尚未計入就累積封印。

CampaignGuide 的資金、職業建議共用，不另造一套付款邏輯。HUD 在首日建議為空時接續遠征建議；暫停與勝敗隱藏。Expedition Guidance 可獨立關閉。提示環只在真實可付款目標吻合時顯示。無存檔欄位、經濟參數或戰鬥規則變更。

## 證據與限制

新增 26 個行為斷言、7 個實際終局場景斷言；完整檢查為 1153 個 Godot 斷言及 2 個 Python 測試。TDD 重現守門者尚未生成卻提示封印、工匠失職仍提示護送、晚建營地 key 錯誤及無晶無法補招募。原生目視另修正範圍內還顯示移動箭頭的問題。

種子 7、居民路線、標準資源從頭操作 865.6 秒雙封印勝利，與修改前相同；自動操作可讀精確敵人預警，不代表真人難度。預覽圖片是控制狀態的視覺測試，未冒充正常資源通關。圖示理解仍待真人，手機實體效能與觸控亦待驗證。
