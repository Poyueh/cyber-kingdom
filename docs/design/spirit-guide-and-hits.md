# 龍晶殘影引導與受擊反應

玩家開局需要看得到、能忽略的身旁引導。沿用首日及遠征建議的真實條件，在騎士身旁放原創龍晶殘影：兜帽、晶核、斷環和拖尾。殘影持續跟隨並指向建議方向，頭頂顯示目標圖示；靠近可付費目標時追加龍晶圖示。取消原固定上方引導卡片。它沒有碰撞、不能付款、不揭露未知資源，也不阻擋任何移動或其他互動。首日建國步驟完成後退場；後續遠征有有效建議時重新出現。暫停／勝敗隱藏，HUD 的引導選項繼續有效。

騎士及敵人的生命下降觸發閃光、後仰、壓縮及回穩；只掉護盾則播放較小的青色抵擋動作。衝刺無敵、治療與升級不能誤觸受擊。居民實際被命中時先保留原職業剪影作短促後仰，再顯示退回流浪者；護民屏障吸收時不播放受傷。敵人死亡短暫倒下消散。

呈現層以實際生命、護盾、居民 hurt 與遊戲時間觀察反應。動畫不新增扣血／擊退／硬直規則，不變更存檔形狀；重開和讀入新 session 清除觀察記憶。驗收包括：反方向探索殘影仍在旁、暫停凍結、真實近戰與居民射擊反應、受防護者不誤判，以及現有引導和戰鬥回歸。
