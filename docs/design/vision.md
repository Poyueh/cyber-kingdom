# 核心方向：最後的避難所

人類靠龍晶驅動機械義肢，在魔法與巨龍統治的世界建立最後的避難所。你是一名改造騎士，每次出征，都必須決定把有限能源用來強化自己，還是保護居民。

## 每次出征的核心抉擇

走進避難所現場投入資源 → 居民自主取器具、建造與守備 → 騎士探索隨機邊境與標記工作 → 工匠採集、搬運與拓荒建設 → 農耕狩獵 → 修復、擴建與強化 → 守成建立王國。龍晶分別在義肢爐和護民塔投入，避免以選單代替世界中的操作。

龍晶是有限的戰略儲備。強化騎士讓探索更安全、可能帶回更多資源；留給避難所能保護居民、維持生產。決策前要看得到成本和可能後果，結果透過實際交戰、居民狀態及設施表現。居民只有遭到未被擋住的實際攻擊才失去身分，不按分配比例在結算時直接受傷。起步先做一個可理解的兩難，不堆技能樹或多種貨幣。

## 設計準則

- 美術以 Kingdom 系列的完成度為目標：精準像素輪廓、自然材質、分層景深、節制光影與流暢動畫。使用者已否定過密插畫與過度簡陋粗像素兩個極端；不硬限 16 色或刻意把人物縮成幾個色塊。保留龍晶機械與中古世界，先透過具體營地樣稿校準細緻度，再製作可玩片段。

- 騎士的機械動作、青綠龍晶光與古城符文共同呈現世界觀；巨龍與魔法支配世界，機械是人類求生的手段。
- 戰鬥要能看懂起手、有效揮擊與收招。衝刺有獨立姿勢及推進效果；敵人危險招式先預警。
- 必經平台用基本走路與跳躍就能通過，留高度和水平距離餘裕。耗能能力可開啟捷徑與額外收益，但不把玩家困在無法完成的必經路線。
- 借鏡 Kingdom 的像素氛圍、橫向可讀性與居民存在感，角色、素材、操作與資源抉擇自行設計。
- 一人、半年、手機優先：先驗證一座避難所、一段出征與一個分配抉擇，再擴充內容。

## 資源邊界

| 資源 | 用途 | 目前狀態 |
| --- | --- | --- |
| 龍晶儲備 | 出征前分配給騎士模組或避難所防護 | 現場義肢爐／護民塔共用有限儲備；重試會重置，不是永久經濟 |
| 義肢充能 CHARGE | 戰鬥中衝刺的短期節奏限制 | 訓練場已實作；程式目前沿用 stamina，會恢復，不代表取得新龍晶 |
| 廢料 SCRAP | 戰鬥回收物，未來用於修建 | 已有擊敗獎勵及存檔；不自動換名或轉成龍晶 |

## 已完成與下一個最小驗證

F5 的避難所入口延伸自[可走動原型](walkable-refuge.md)，現在進入隨機邊境：投放補給招攬、工程錘與守備器具自動就職、現場防線建造升級、三波實際夜襲。原先「3 顆龍晶／居民自動受傷」選單仍保留供歷史比較，不再作為主要操作與居民受擊方向。

騎士可親自交戰以保護居民，也可把有限龍晶投入自己的護盾或護民塔；廢料用於招攬、器具及建設。最新 [邊境經濟原型](frontier-economy.md) 已加入種子地圖、有限採集、農夫／獵人、城鎮與騎士成長及本輪王國目標。尚無永久存檔、野外敵群與完整商業版內容；先取得整段循環的試玩回饋。

居民主導擴展：騎士的劍只用於交戰。資源點由 E 下達工作標記，居民領取工程器具後前往、作業與搬運；拓荒站提供向外發展的實際收貨節點。
