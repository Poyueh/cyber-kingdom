# 核心方向：最後的避難所

人類靠龍晶驅動機械義肢，在魔法與巨龍統治的世界建立最後的避難所。你是一名改造騎士，每次出征，都必須決定把有限能源用來強化自己，還是保護居民。

## 每次出征的核心抉擇

避難所分配龍晶 → 選擇騎士改裝與居民防護 → 橫向探索、戰鬥與撤退 → 帶回資源、承受防護不足的後果 → 下一次分配。

龍晶是有限的戰略儲備。強化騎士讓探索更安全、可能帶回更多資源；留給避難所能保護居民、維持生產。決策前要看得到成本和可能後果，結果透過居民狀態及設施表現，避免只有抽象數字。起步先做一個可理解的兩難，不堆技能樹或多種貨幣。

## 設計準則

- 騎士的機械動作、青綠龍晶光與古城符文共同呈現世界觀；巨龍與魔法支配世界，機械是人類求生的手段。
- 戰鬥要能看懂起手、有效揮擊與收招。衝刺有獨立姿勢及推進效果；敵人危險招式先預警。
- 必經平台用基本走路與跳躍就能通過，留高度和水平距離餘裕。付費能源能力可開啟捷徑與額外收益，但不把玩家困在無法完成的必經路線。
- 借鏡 Kingdom 的像素氛圍、橫向可讀性與居民存在感，角色、素材、操作與資源抉擇自行設計。
- 一人、半年、手機優先：先驗證一座避難所、一段出征與一個分配抉擇，再擴充內容。

## 已完成與下一個最小驗證

目前只有鑄造場訓練、騎士／守衛戰鬥、廢料存檔與四段平台路線。背景中的城堡與龍影不是已實作的避難所或龍戰。

下一個獨立原型：同一份有限龍晶，選擇提供騎士護盾或居民防護。畫面呈現少量居民與一次可預見的威脅，跑完一輪後明確比較騎士生存與居民受損。先用測試保證分配不超支、效果只套用一次與重開一致，再接場景。是否好玩由試玩決定，尚不承諾完整經濟或隨機關卡。
