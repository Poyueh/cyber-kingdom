# 核心方向：最後的避難所

人類靠龍晶驅動機械義肢，在魔法與巨龍統治的世界建立最後的避難所。你是一名改造騎士，每次出征，都必須決定把有限能源用來強化自己，還是保護居民。

## 每次出征的核心抉擇

避難所分配龍晶 → 選擇騎士改裝與居民防護 → 橫向探索、戰鬥與撤退 → 帶回資源、承受防護不足的後果 → 下一次分配。

龍晶是有限的戰略儲備。強化騎士讓探索更安全、可能帶回更多資源；留給避難所能保護居民、維持生產。決策前要看得到成本和可能後果，結果透過居民狀態及設施表現，避免只有抽象數字。起步先做一個可理解的兩難，不堆技能樹或多種貨幣。

## 設計準則

- 騎士的機械動作、青綠龍晶光與古城符文共同呈現世界觀；巨龍與魔法支配世界，機械是人類求生的手段。
- 戰鬥要能看懂起手、有效揮擊與收招。衝刺有獨立姿勢及推進效果；敵人危險招式先預警。
- 必經平台用基本走路與跳躍就能通過，留高度和水平距離餘裕。付費能源能力可開啟捷徑與額外收益，但不把玩家困在無法完成的必經路線。
- 借鏡 Kingdom 的像素氛圍、橫向可讀性與居民存在感，角色、素材、操作與資源抉擇自行設計。
- 一人、半年、手機優先：先驗證一座避難所、一段出征與一個分配抉擇，再擴充內容。

## 資源邊界

| 資源 | 用途 | 目前狀態 |
| --- | --- | --- |
| 龍晶儲備 | 出征前分配給騎士模組或避難所防護 | 獨立原型已實作分配與一輪結算；重試會重置，不是永久經濟 |
| 義肢充能 CHARGE | 戰鬥中衝刺的短期節奏限制 | 訓練場已實作；程式目前沿用 stamina，會恢復，不代表取得新龍晶 |
| 廢料 SCRAP | 戰鬥回收物，未來用於修建 | 已有擊敗獎勵及存檔；不自動換名或轉成龍晶 |

## 已完成與下一個最小驗證

目前已有鑄造場訓練、戰鬥、廢料存檔、四段平台與獨立龍晶分配原型。背景中的龍影仍不是可交戰巨龍。

龍晶原型可選擇 3 顆能源分配：每顆供騎士 20 點消耗式護盾，或保護一名居民；出征對抗現有守衛，勝利、撤退與倒下均結算一次魔潮。居民用防護罩與受傷標記呈現後果，重試還原初始條件供比較。原型採記憶體進度，沒有改動原有廢料存檔。

驗證問題：玩家是否願意犧牲自己的安全來保護居民？熟練玩家能否靠戰鬥技巧省下龍晶？這些是待試玩回答的問題，測試通過只證明規則正確。下一步再決定是否延伸成可走動避難所、回收龍晶與下一次出征；尚無居民生產、永久受傷、隨機關卡或長期經濟。
