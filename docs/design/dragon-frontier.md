# 荒地、居民與最終巨龍

## 本輪玩法

新旅程從營火左方 1050 世界單位的荒地開始，殘影在前方招手，引導玩家走向營火；可以不跟從。每側外圍區域預設由 3 增至 5，仍由種子產生资源和地形。未知地帶使用重疊柔邊霧粒，隨時間飄移、靠近與發現後淡出，取消直線遮罩。

閒置工匠巡遊工坊附近；守衛白天巡邏指定防線、接敵和夜晚恢復防守；獵人優先尋找已探索範圍內且能在天黑前往返的獵物，找不到獵物時巡獵；農夫在田間來回工作。晚上仍遵守回營安全餘裕，不把外出漫遊當作生產收益。

## 最終目標

封印左右兩門只會召喚巨龍。擊敗巨龍且清除殘敵，才算勝利；核心或騎士死亡仍是失敗，敗北優先。

| 調整項 | 初始值 |
| --- | --- |
| 最低強度日數 | 第 6 天 |
| 生命 / 傷害 | 1800 / 36 |
| 晚於基準日，每天增加 | 240 生命 / 4 傷害 |
| 吐息預警 / 冷卻 | 1.6 秒 / 4.4 秒 |

第 1～6 天召喚強度相同，第 7 天為 2040／40；召喚時鎖定強度，跨日不會在戰鬥途中再加強。這使玩家需權衡準備軍隊與延後封門。數值是待試玩的第一版，不是最終平衡。

巨龍朝目標移動、鎖定吐息落點，再造成範圍傷害；城牆能攔截吐息，騎士可閃離或跳開。守衛群射不被共用無敵時間吞掉；騎士仍受每刀一次命中限制，連斬不能永遠取消首領吐息。Boss 的畫面受擊反應獨立於傷害無敵。

## 手機控制

左半部左右拖曳控制方向和速度，放開停止。右側空白區往下拖：在互動範圍內投入一顆龍晶／開啟寶箱，持續按住會填滿當前一筆交易；範圍外丟出一顆。單次手勢不跨到下一筆升級。攻擊、跳躍、衝刺維持右下按鍵。不同手指獨立，切背景或暫停會取消手勢。鍵盤操作不變。

## 架構與紀錄

DragonRules 提供純強度規則，CampaignSession 決定召喚，DragonAssault 處理戰鬥；畫面、手勢、霧與素材只在 presentation。CampaignTuning 的 Resource 將數值送進應用層。

快照升為 v4，接受 v1～v3 遷移；舊存檔保留地圖、位置與已達成勝利。尚未通關的舊旅程採用巨龍目標。新地圖和荒地起點需新建旅程。損壞、未知版本和矛盾首領狀態仍拒絕覆蓋。
