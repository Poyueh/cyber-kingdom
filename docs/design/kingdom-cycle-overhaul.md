# 清地、擴建與騎士體力

驗收情境：騎士走入森林，先用龍晶指定居民清理；一棵樹完成仍不能拓建，區內所有樹木、礦產／寶箱移除後才出現拓荒站及防線候選。走近看到低矮石基與浮空龍晶空格，逐顆投入，居民施工。這採用 Kingdom 的現場投入思路，沒有複製其美術。

- 清理定義是 harvest node 的 `collected`，不是 `marked`；樹、龍晶礦、石礦、寶箱阻擋拓建，莓果與藥草不阻擋。工匠仍負責採集，騎士直接開寶箱。拓荒站需已有一批實際交貨以確定收貨位置。
- 已建成或已付款施工的設施保持可見，避免載入舊進度時建築消失。城牆仍需要聚落等級、拓荒站、前一道防線；全數清地不會跳過這些前提。
- 清光森林會沿用既有生態代價：流浪者營地與獵物不再補充。玩家需選擇保留林地或向外擴建。
- 夜襲出生點只由兩端地獄之門決定。城牆推進不會改變出生點；已封印一側不再出怪。入侵未解決時不會因倒數歸零而直接天亮。
- 新增十二種景物，森林、採石場、遺跡各有組合；換種子改變位置。同一存檔仍保持同樣分布，裝飾不參與採集數值或碰撞。
- 攻擊每刀 12、跳躍 18、衝刺 30 體力；各項可在 CampaignTuning 調整。連技預約不扣費，真正出刀時重新檢查並扣費。跳躍只有起跳成功扣費，空中重按不扣。耗盡後不能使用不足額技能，原本恢復規則持續生效。
- 武器訓練與義肢電容等級控制劍刃、鎧甲、光路的配色，三級依序可辨；idle、run、dash、combo 共用材質。這次是裝備配色變化，沒有替換成全新鎧甲輪廓。
- 桌面隱藏觸控方向、攻擊、跳躍、衝刺、投入、丟晶按鈕，保留鍵盤操作和附近 E 提示。手機保留觸控按鈕，移除全螢幕和 E 提示。暫停才顯示音量、手動存讀檔與重開操作。
- 音樂和音效音量分別保存到音訊偏好檔；暫停可預聽音樂，切到背景則停止所有聲音。新增一段原創合成循環配樂。暫停選單的磁碟儲存獨立手動檢查點，回轉箭頭還原；五秒自動存檔不覆蓋手動檢查點。

## 維護與存檔

存檔 schema 升為 2。已知 v1 在副本中補上騎士攻擊／跳躍成本，敵人保留 0；所有原有內容仍需完整驗證。未知版本、壞檔不自動覆蓋。沿用 `campaign_v1.json` 路徑以找到玩家舊進度；內容版本由 `version` 判定。手動槽為同一路徑加 `.manual`。載入保持暫停並清除按住的操作，不回放付款。

`domain` 決定可清地、體力與出生位置，`application` 協調互動與存檔，`presentation` 負責景物、材質和 UI，`infrastructure` 處理音量檔案，`bootstrap` 連接選單與遊戲。沒有新增外部服務或訂閱依賴。

## 驗證範圍

世界规则與體力先重現失敗再實作；真實場景另驗證居民清理、按鍵消耗、手機觸控、手動存讀檔與音量重開。原生渲染檢查去背、石基、浮空投入、兩端出生與裝備配色；完整測試及遊玩結果見 STATUS。手機版的實機觸控手感與 Windows 實機效能仍需使用者裝置驗證。
