# 持續招募與邊境生態
2026-09-13。將有限開箱／採礦之外的恢復途徑接到既有日夜循環。

## 一晚之後會發生什麼
真正熬過夜襲、日曆進入下一天時，每個仍有效的探索營地最多補一位流浪者。地圖六個區域各有一處營地；預設每處最多兩位等待者，全地圖總人物最多 24（包含居民與流浪者）。靠近營地以人形、等待數／上限、太陽表示日出補員；達到全局上限改顯示總人物數與鎖。

新來者仍需一顆龍晶招攬，並自行找器具就職；沒有免費直接分配居民。新人的出生點與原有角色錯開，避免招募選錯人。人物索引持續穩定，原有居民不會為了騰出名額被刪除。失去職業的居民仍可重新招攬，沒有按日曆直接扣人口。營地內等待額依仍是流浪者、原屬區域與 160 單位範圍判斷。

森林每次日出會補回已獵取的兩個獵物位置。獵人照原有方式走近狩獵、每隻取得 2 食物；4 食物可在營地交易成 2 龍晶。獵物位置會依天數產生小幅、可重現的變化，沒有無限增加動物清單。

已採完且送達的莓果與藥草在日出再生，需要重新投入標記與由工匠採集搬運；不直接給庫存。手上尚在搬運或地上尚未交貨的採集物不會再生，避免一份貨被複製。植物在清林空地仍可生長。樹木、礦石與寶箱保持有限，不在夜間突然重置；原有農耕仍持續留種生產。

## 清林取捨
只要森林保留至少一棵未砍下的樹，該區就保留招募與獵物再生。最後一棵被採集後，新人與新獵物停止補入，營地火堆變為冷石堆；原有流浪者、居民與尚存活動物仍保留。非森林的遺跡／礦區營地不受樹木數影響。

選擇最後一棵尚未標記的樹時，投入泡泡會畫劃除的人形與獵弓。已標記等待工匠的樹也計入預定清理，因此警示會在排滿最後一筆伐木前出現。這是情報提示，玩家仍能自主下令；騎士不親自砍樹。

驗證發現原每棵 3 木材時，保留每片森林一棵只能取得 18 木，農場與三級聚落合計需要 22 木，等同逼迫全砍。主戰役改成每棵 4 木：採六棵取得 24，農場與聚落用 22，剩 2，同時保留兩處森林來源。舊獨立 Frontier 原型不改。這是木材可行性驗證，並未代替龍晶投入、工人路程、糧食與石材的整局測試。

## 維護入口
campaign.tres 的 Frontier Renewal：
- Tree Timber：主戰役每棵木材，預設 4。
- Population Limit：地圖人物總上限，預設 24。
- Camp Waiting Limit：各營地等待人數上限，預設 2。

FrontierEcology 管理棲地、等待名額、出生空位與再生；傳回新增人物請求，由 CampaignSession 建立角色。只在實際 Calendar dawn 轉換觸發，重複更新、暫停、夜襲未清完及終局不會刷新。手動測試調整 day 不會被當作已熬過一夜。CampaignView 使用目前玩家位置與公開生態資料顯示提示，不決定資源增減。

## 驗證及限制
TDD 先得到缺少生態規則的六個失敗；補規則後，實際觸控招募測試抓到同座標出生的錯誤，修正為找空位。另以失敗測試修正保留森林卻缺木材的預算，以及植物被錯誤綁在森林存續的條件。行為涵蓋再生僅一次、等待／全局上限、真實招募付款、搬運不複製、有限礦藏不重置、清林保留舊人物／動物與素材收支。

乾淨標準設定的完整回歸通過 924 項 Godot 斷言（715 行為、209 場景）及 2 個 Python 建置測試，架構、匯入、錯誤掃描與主場景啟動通過。

實際場景從日出、新人選取、觸控招募，接到獵物再生、獵人取得食物與現場交易龍晶；亦驗證暫停與重開。[日出營地](../previews/renewal-camp-v001.png)、[最後一棵樹提示](../previews/clearcut-warning-v001.png) 為原生渲染，沿用現有素材。視覺 fixture 直接調整日夜與採集狀態以展示結果，並非真人或標準預算完整通關。

目前仍有固定兩側防線、未完成存續檔與手機實機、缺少三個種子的兩條投資路線整局證據。持續收入的機制接通不等於難度適中；需在拓展與完整路程中測量可用工時、晶體、糧食、損失及恢復速度。
