# 場景連續性、探索淡入與騎乘

森林視差與河岸改用固定世界相位、交替鏡像貼圖；相鄰片段以同一來源邊緣相接。繪製範圍隨目前可見區域多延伸一段，鏡頭在兩端留 160 世界單位，讓騎乘剪影不被畫面裁掉。這是有邊界的探索地圖，沒有把地圖左右接成環形。

ExplorationReveal 在新發現後以 1.8 秒 smoothstep 漸變。資源、裝飾、獵物、流浪者、營地提示及兩端門逐漸出現，霧反向淡出；時間取自模擬，暫停不繼續播放。載入原本已探索區域直接顯示，不重新遮蔽。探索判定與工作規則不改變。

地上龍晶放大 35%，世界圖示放大 30%；投入空格半徑 6→8、間距 18→23。保留圖示為主的介面與近距離互動方式。

居民、流浪者與一般怪物使用原有圖像和動畫，將頭部繪製放大、軀幹及腿部縮短，約三頭身；工匠的施工／搬貨／爬梯與受擊、死亡也使用同一比例。騎士步行比例及巨龍保持原設定。

劍術與義肢電容都達到各自最高階時自動騎乘。一般預設為 3／3；移速 ×1.25、衝刺速度 ×1.15，跳躍和體力成本不變。保留第一刀站定、連斬前進與每刀命中限制。騎乘狀態從既有升級數值推導，無新貨幣或存檔欄位，舊滿級紀錄可直接騎乘，新旅程重新步行。

六張騎乘姿勢是本輪初版；真機手感、完整騎乘劍路與難度平衡仍需後续試玩。
