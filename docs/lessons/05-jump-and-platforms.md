# 第五課：調整能實際跳上的平台

這次練習只改一個平台的寬度，理解「看得見」與「碰得到」必須一致。

1. 在 Godot 開啟 `scenes/training.tscn`，選取 PlatformStep1。
2. 在 Inspector 找到 Width，目前是 **150**。改成 **170**，場景中的平台和碰撞會一起變寬，不需要各改一次。
3. 按 F5，以 A／D 與 Space 走跳：先上第一個平台，再走近右緣跳向下一個，連續通過四段。這條路線不需要 L 衝刺。
4. 停止遊戲，把 Width 恢復 **150**。若想改高低，在 Transform 的 Position 修改 Y；Y 越小，平台越高。

本版把 Jump Speed 改為 520，Gravity 保持 1100，實際最高約 119 像素。舊版最高約 77 像素，卻有高 82 與 98 像素的平台，確實無法從地面跳上。即使高度足夠，平台太遠仍可能失敗，因此需要真的走完路線。

[實際平台路線預覽](../previews/refuge-route-v001.gif)。如果感覺必須精準踩邊才跳得到，要繼續調寬平台或縮小間距；「測試通過」不代表手機上已經好操作。

後續關卡遵循[核心方向](../design/vision.md)：有限龍晶用來選擇騎士強化或居民防護，基本通行不能因能源耗盡而卡死。提供本課不代表你已完成練習，等你實際操作後再記錄理解程度。
