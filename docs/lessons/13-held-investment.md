# 第十三課：調整長按投入的節奏

1. Godot FileSystem 選 `data/campaign.tres`。
2. Inspector 展開 **Hold to Invest**。
3. **Investment Hold Delay** 預設 0.5 秒：按住多久才投入第二顆。試改成 0.8，短按和長按會更容易區分。
4. **Investment Interval** 預設 0.28 秒：後續每顆間隔。先保留原值，避免一次改太多。
5. F5 → REFUGE／避難所，按住 E 或投入圖示建立營地。第二格旁的圓環就是等待下一顆的進度。

短按依然只投一顆，放開後未完成的格子會保留。完成一筆就停止；想買下一件器具或升下一級，要再按一次。跳躍、走離目標或暫停會取消當次長按。

這次的輸入分成兩件事：「按下」決定先付一顆，「持續按住」決定要不要繼續同一筆投資。`application/investment_hold.gd` 管手勢規則，圖示只把手指或鍵盤狀態交給它，所以兩種操作會有一致的結果。
