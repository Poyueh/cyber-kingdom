# 第三十二課：在電腦預覽手機安全區

開啟 scenes/frontier.tscn，選場景裡的 HUD（掛著 campaign_hud.gd）。在 Inspector 找到 Preview Safe Margins；四個值依序代表左、上、右、下，單位是遊戲畫面裡的邏輯像素。

暫時設為 (80, 12, 20, 26)，按 F6。左側按鈕和上方資訊會向內排列，模擬橫握時左邊有瀏海。再交換左右的 80 與 20，就能檢查另一個橫握方向。

完成後改回 (0, 0, 0, 0)。全零表示讓手機讀取真正安全區；留下測試值會覆蓋裝置偵測。這個設定只改介面位置，不會移動騎士或改變地圖。

Viewport 是遊戲繪製的畫布；手機的實體像素和畫布座標可能不同，所以不能直接把手機回報的缺口寬度當成按鈕位移。這版集中在 CampaignLayout 換算，日後調整間距只需要改一個地方。
