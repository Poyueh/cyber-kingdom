# 第六課：修改每顆龍晶的護盾量

這次不用改角色動作，只練習修改一個玩法數值。

1. 在 Godot 開啟 `scenes/refuge.tscn`，選最上方 Refuge 節點。
2. 在 Inspector 點開 Tuning 資源，找到 **Shield Per Crystal**，目前是 **20**。
3. 改成 **25**，保存，按 F6 執行目前場景。選「騎士 2 / 避難所 1」，預覽護盾應是 **50**。
4. 出征後看左上角 SHIELD；守衛打中時先減護盾。按 R 撤退，結果顯示本次實際擋下多少傷害。
5. 練習後恢復 **20**。Crystals 和 Residents 分別控制本輪龍晶數與居民數，這次先不一起改。

一般試玩則按 F5，在訓練場下方點「REFUGE / 龍晶分配」。一輪只測一個取捨：護住自己，還是讓更多居民安然無恙。原型每次重試都還原居民與能源，所以可以在相同條件比較。

護盾和 CHARGE 不同：護盾是龍晶的防護結果，本輪耗掉就不回復；CHARGE 是衝刺節奏資源，仍會逐漸恢復。這次的廢料只是暫存試驗，不影響原本訓練場存檔。
