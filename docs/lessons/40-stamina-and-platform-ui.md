# 第四十課：調整體力消耗

這次只練習一件事：不用改程式，讓跳躍比較省力。

1. 在 Godot 的 FileSystem 找到 `data/campaign.tres`，點選它。
2. 右側 Inspector 展開 **Knight stamina**，找到 **Jump Stamina**；預設是 18，改成 10 並儲存。
3. 打開 `scenes/frontier.tscn`，按 F6 執行目前場景。若自動載入舊進度，先在暫停選單建立手動存檔，再用地圖圖示開始新地圖，讓新的設定生效。
4. 跳躍幾次，看左上方綠色體力條。改回 18 比較；空中重按不會重複扣體力。

Resource 是一份可編輯的設定資料。這次的 Resource 告訴遊戲「跳一次需要多少體力」，扣除體力的規則在內層，畫面只讀結果；以後改數值不用到角色動畫裡找程式。

同一組的 **Attack Stamina** 與 **Dash Stamina** 分別影響每次實際出刀及衝刺。設成比體力上限還大，技能便無法使用。新設定只用於新開的遊戲，已保存的當局仍帶著自己的參數。

桌面用 A／D 移動、J 攻擊、L 衝刺、空白鍵跳躍、E 投入、Q 丟晶；Esc 開選單。手機顯示對應觸控圖示。選單音符調音樂，喇叭調音效，磁碟存手動進度，回轉箭頭讀取；讀取後按播放圖示繼續。
