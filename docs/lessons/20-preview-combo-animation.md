# 第二十課：直接試玩目前場景

Godot 的 **F5** 執行專案設定的入口；本專案目前入口是訓練場，不是營火戰役。

要看這次的新動作，在左側 FileSystem 雙擊 `scenes/frontier.tscn`，確認它成為上方目前場景，再按 **F6**。按 J／劍圖示連斬，接著一邊左右移動、一邊接招；特別看回挑的抬腰與重劈的前壓。

本課先只練習「F6 執行目前場景」，不改任何數值。角色動畫素材配置在 `data/knight_combo_motion.tres`；接招玩法配置在 `data/knight_combo.tres`，兩者用途不同。

尚未收到你的操作回饋，因此不會把這個操作記為已掌握。
