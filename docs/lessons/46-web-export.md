# 第四十六課：HTML 入口與網頁遊戲資源

在 Godot「專案 → 匯出」會多出 `Web Demo`。它使用同一份遊戲場景和 GDScript，匯出時把引擎轉成瀏覽器能載入的檔案。

- index.html：玩家開啟的入口。
- index.wasm / index.js：瀏覽器執行的引擎。
- index.pck：地圖、角色和玩法資源。
- guide.html：獨立的圖文玩家指南。

小練習：查看 builds/web-20260914-r3/web 的檔案，再開啟本機試玩網址。不要把 index.html 單獨搬走；遊戲需要同資料夾的其餘檔案。可以單獨分享的是壓縮包內的 guide.html。

開新瀏覽器不代表沿用原本的桌面存檔。這次存檔放在瀏覽器的網站資料中。尚未收到練習回報，不記為已掌握。
