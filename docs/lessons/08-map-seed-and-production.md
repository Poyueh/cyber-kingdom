# 第八課：重現地圖，再調整農田節奏

本輪先認識 Resource：它保存可調數值，程式讀取它來建立本輪世界。你不用先改程式才能比較玩法。

1. 在 Godot 左下 FileSystem 找到 `data/frontier.tres`，點一下。
2. 右側 Inspector 找到 **Map Seed**。先記下原值 `742601`，改為 `742602`。
3. F5 → REFUGE / 避難所，觀察上方地圖編號及外側區域位置。R 重玩應保持這個地圖；N 才換下一張。
4. 停止遊戲，回到同一份 Resource，展開 **Production**，把 **Farm Cycle** 從 12 改成 8，再試玩有農夫工作的田。應更快收成；無農夫仍不產糧。
5. 比較後把值還原。這次的探索與生產進度不會存檔。

只改一個數值比較，才知道是什麼影響感受。`data/settlement.tres` 是上一版獨立場景的設定；這次使用 `data/frontier.tres`。不要直接改 `domain/frontier.gd` 裡的預設值來做日常平衡。

你可以回報「這張地圖編號＋我走到哪裡＋問題」，我就能重現同一組配置。提供這份練習不代表已記錄你學會，等你試過再接下一個概念。
