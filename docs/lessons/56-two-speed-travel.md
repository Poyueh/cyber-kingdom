# 第 56 課：調整快跑，不改程式

在 Godot 左邊 FileSystem 找到並點選 `data/campaign.tres`，右邊 Inspector 展開 **Fast running**。

- **Fast Run Multiplier**：快跑倍率，現在是 1.65。試改為 1.4，騎士的第二段拖曳就會慢一些。
- **Fast Run Drain**：快跑每秒消耗體力，現在是 18。數字越大，能連續快跑的時間越短。

儲存後開新旅程測試：手機短拖與長拖，或電腦 A/D 與 Shift + A/D。比較速度與綠色體力條，測完可以改回原值。舊旅程保留它建立時的部分設定，使用新旅程比較比較可靠。

這類設定檔叫做 **Resource**。我們把「數值」獨立出來，未來你調手感時，就不必先懂程式碼。

本課已提供操作步驟，尚未確認使用者完成練習。
