# 第二十一課：找到戰役的攻擊美術

在 Godot 左側 FileSystem 點選 `data/knight_combo_motion.tres`。右側 Inspector 的 **Planted Atlas** 是原地斬擊圖，**Moving Atlas** 是移動斬擊圖。

這次兩張圖都指向 `art/characters/combo-v003/`，內容是斜切、反手橫掃與踏步斜斬。它們仍使用同一套連招規則；換這裡的圖不會增加傷害。

先只練習找到這兩個欄位，不必改值。接著雙擊 `scenes/frontier.tscn`、按 **F6**，連按 J 並觀察第二刀的橫掃。F5 會先進入訓練入口。

尚未收到你的操作示範，因此本課仍只是已提供的練習。
