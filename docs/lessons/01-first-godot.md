# 第一課：先會打開，再改一個數值

今天只需要認識四件事，暫時不用背程式。

- **Node／節點**：遊戲中的一個元件。例如 Knight 是有碰撞能力的 CharacterBody2D，HUD 是疊在畫面上的 CanvasLayer。
- **Scene／場景**：保存一組節點。`scenes/actor.tscn` 是可重複使用的角色，`scenes/training.tscn` 把角色、地板、攝影機與 HUD 組合成訓練場。
- **Script／腳本**：定義行為。`presentation/actor_body.gd` 負責物理移動和畫出角色，傷害規則則在 `domain/combatant.gd`。
- **Resource／資源**：可保存、重用和在 Inspector 修改的資料。`data/knight.tres` 是騎士的能力設定。

## 打開遊戲

1. Godot 專案管理員 → Import → 選專案根目錄的 `project.godot`。
2. 打開後，左側 FileSystem 找 `scenes/training.tscn`，雙擊。
3. 左側 Scene 樹選 Knight，可看到它的碰撞與 Camera2D。
4. 按 F5 執行整個專案；F6 只執行目前場景，今天先用 F5。
5. A/D 移動、Space 跳躍、J 攻擊、L 衝刺。切出遊戲會暫停，Esc 可恢復。

## 第一個小練習：調整傷害

1. 停止遊戲，雙擊 `data/knight.tres`。
2. 右側 Inspector 展開 Combat，將 Damage 從 **25 改為 35**，保存。
3. 再按 F5。守衛有 100 HP，成功命中的攻擊應從四次變三次。
4. 敵人受傷後短暫無敵，所以不是每次按 J 都算成功命中。觀察血條。
5. 練習結束可改回 25；日後真的要改平衡時，我們會將數值改動也提交到 Git。

這就是把「資料」和「規則」分開的好處：調傷害不需要改角色移動或存檔程式。核心測試使用自己建立的測試數值，改 `.tres` 不會自動改變所有測試預期；設計上的平衡仍要試玩。

## TDD 是什麼

我們先描述一個可驗證的規則，例如「同一刀不能連續扣兩次血」，先看到測試因規則尚未實作而失敗，再讓程式通過，最後整理程式。這叫紅 → 綠 → 重構。

下一次你只要告訴我手感：移動太快、跳太高、攻擊太慢，或觸控位置不舒服。我會把意見變成具體改動，必要時先補測試，也會告訴你在哪裡可以自己調。
