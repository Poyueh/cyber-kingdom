# 第四十七課：發行版本與 Git 標籤

在 Godot「專案 → 匯出」查看 macOS 或 Windows 的 Application 區域，可看見這次統一成 0.0.1 的版本號。版本號是玩家下載到的檔案標示；Git 的 v0.0.1 標籤則固定這次程式來源。

GitHub Release 附件提供 Windows、Mac 與 Web 三種成品；Pages 會取同一個 Release 的 Web ZIP 發布。因此下載版與網頁版有可追溯的來源。

小練習：在 GitHub Release 找到 v0.0.1，再對照 export_presets.cfg 的版本欄位。先看懂它們的對應，不需要修改。未收到練習回報，不記為已掌握。
