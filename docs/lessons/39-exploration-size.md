# 第三十九課：調整新一局的探索範圍

在 Godot 的 FileSystem 選取 `data/campaign.tres`，到 Inspector 的 **Exploration → Outer Regions Per Side**。

這個值表示每側額外的區域數：3 是本次預設（左右各增加三段），0 是原本大小。地圖內容由種子固定，不是單純拉寬背景圖片。

開 `scenes/frontier.tscn` 後按 F6，暫停並點地圖圖示開始新局，才會使用新的大小。既有存檔會保留當局地圖。換圖會開始新一局，因此先確認目前這局已不需要繼續。

可先試 2 與 3，比較往返營火的時間。這次只調這個欄位，不必同時修改白天長度或人物速度。教材已提供，尚未有使用者實際操作的掌握紀錄。
