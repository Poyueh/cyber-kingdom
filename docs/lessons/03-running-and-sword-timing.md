# 第三課：調整跑步動畫速度

這次只練習一件事：改變跑步畫格播放速度，觀察它和角色移動速度的差別。

1. 在 Godot 開啟 `scenes/knight_visual.tscn`，選 KnightVisual。
2. 點 Inspector 的 Sprite Frames，選下方的 `run` 動畫；現在是六格、12 FPS。
3. 把 FPS 改成 8，保存，再按 F5。按 A 或 D，觀察腳步循環變慢，但角色通過相同距離所需時間沒有因此改變。
4. 練習後把 run 恢復成 12 FPS，保存。移動速度由另一份 `data/knight.tres` 的 Move Speed 控制。

可以把 FPS 想成「每秒換幾張圖」，Move Speed 則是「每秒走多遠」。先理解這兩件事即可，不用現在讀動畫程式。

揮劍是特例：為了讓劍碰到敵人的時間與扣血一致，遊戲用戰鬥進度選格。只改 `attack` 的 FPS 會改變編輯器預覽，F5 遊戲的整刀速度仍由 `data/knight.tres` 的 Attack Duration 控制，預設為 0.22 秒。新版六格下劈前 40% 是舉劍，40% 至 75% 能命中，最後四分之一收招。成功命中時另加短暫停頓，詳見第四課。

[實際遊戲近景展示](../previews/foundry-cleave-v002.gif) 包含左右跑步和四次揮劍；拍攝時放大鏡頭方便看動作，遊戲預設鏡頭沒有改變。跳躍與衝刺專用動畫將在後續製作。

試完可回報：FPS 從 12 改成 8 時，角色是走得更慢，還是腳步換圖更慢？收到你的實際回饋後才更新學習紀錄。
