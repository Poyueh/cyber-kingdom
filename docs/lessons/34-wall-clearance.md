# 第三十四課：看懂建牆需要清理的範圍

在 Godot 檔案面板選 data/campaign.tres，在 Inspector 展開 Defense Posts，找到 Wall Clearance。預設 80，代表牆位左右各 80 世界單位內不能有仍站立的樹。

這不是「整片森林要砍光」。已委託但工匠尚未砍完的樹仍會擋住施工；牆位旁的樹也可能屬於隔壁區域。先看遊戲中牆頭的樹圖示數量，再觀察工匠完成後是否減少，比直接調小數值更容易理解規則。

若想比較，可以在測試副本把 80 暫改 60。它改的是清地門檻，不是城牆血量或居民速度；正式測試數值仍維持 80。這輪沒有改你的個人 Resource。
