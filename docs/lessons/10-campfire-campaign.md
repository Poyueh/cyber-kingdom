# 第十課：調整自己的龍晶背包

這次只改一個數字，觀察「背包容量」和「場景裡的掉落」如何分開。

1. 在 Godot FileSystem 點選 `data/campaign.tres`，右側 Inspector 展開 **Knight Backpack**。
2. 將 **Backpack Capacity** 從 12 改為 6；**Initial Crystals** 保留 12。
3. F5 → REFUGE／避難所。背包應顯示 6/6，營火旁留下放不進去的龍晶。
4. 靠近營火，按兩次 E 填滿兩格。花掉的空位會讓騎士撿回附近龍晶；地上的數量隨之減少。
5. 完成後把容量還原 12，按 R 開始相同地圖的新一輪。

這個 `.tres` 是遊戲設定 Resource。畫面只把背包和投資結果畫出來；扣款、容量與掉落由內層規則處理，所以換 UI 不應改變你持有的龍晶數量。

目前沒有戰役存檔。R 重玩同圖、N 換圖都會清空這輪王國。你是否已掌握這個操作，仍以你的實際回饋為準。

先前第九課的採集時間設定，現在也在 `data/campaign.tres` 裡；工匠器具改為每次投入一顆、共 2 顆龍晶，資源點委託需 1 顆。
