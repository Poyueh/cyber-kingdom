# 第十一課：調整角色在畫面中的大小

1. Godot FileSystem 點 `data/campaign.tres`。
2. Inspector 展開 **Presentation**，將 **Camera Zoom** 從 1.15 改成 1.25。
3. F5 → REFUGE／避難所。角色和場景會更近，但圖示操作區大小不變。
4. 比較能看到的左右範圍，試完可還原 1.15。

鏡頭只改你看到的比例，不改跳躍高度、移動速度或攻擊範圍。圖示 UI 使用獨立畫布，所以放大角色不會連帶擠大操作按鈕。

右上四角圖示可切換全螢幕；兩條直線是暫停。暫停後出現地圖、回轉箭頭、劍三個圖示，分別是換圖、重玩和回訓練場。R／N 仍會重置本輪，尚無戰役存檔。
