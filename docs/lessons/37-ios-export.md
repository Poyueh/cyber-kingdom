# 第三十七課：認識 iOS 匯出設定

在 Godot 選 Project → Export，點 iOS Demo。Application 區域可看到 App Store Team ID、Bundle Identifier，以及已勾選的 Export Project Only。

Team ID 是 Apple 團隊的代碼，Bundle Identifier 是這個 App 的識別。兩欄目前留白，等實際 Xcode 帳號可用再填；不要用網路範例的代碼代替自己的。Export Project Only 表示先產生 Xcode 專案，還不是能安裝的 iPhone App。

這次先認識設定位置即可。完整 Xcode、簽署與裝置安裝尚未完成，未把閱讀教材當作已操作成功。
