# 第七課：調整第一次夜襲的準備時間

這次只改一個數值，讓你有更多時間看懂居民自主行動。

1. 開啟 `scenes/settlement.tscn`，選最上方 Settlement 節點。
2. 在 Inspector 展開 Tuning，找到 **First Raid Seconds**，預設 55 秒。
3. 改為 90，保存，按 F6。左上角倒數會從約 90 開始。
4. 先招攬兩名居民，再到工坊與武器坊供應器具，最後在防線投入建造。觀察他們自行拿器具、前往工作位置。
5. 練習後恢復 55。先不用同時修改速度與起始資源，才知道是哪一項造成差異。

E 與畫面「投入」都使用同一套附近判斷。沒有工程師時，付費工單會等待；這不代表付款失敗，不需連續再按。

居民受擊變回流浪者之後，你可以再次給補給招攬，然後補一件新器具讓他重新就職。這比舊選單的自動受傷結算更接近這次要驗證的循環。

本課不調角色動作；是否已理解，以你的實際回饋為準。
