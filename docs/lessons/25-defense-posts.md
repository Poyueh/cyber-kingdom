# 第二十五課：調整左側防線位置

在 Godot 的 FileSystem 選 data/campaign.tres，於 Inspector 展開 Defense Posts，可以看到 Left Defense X，預設 -1100。負數代表營火左側；若暫時改成 -1000，左防線會往營地靠近 100 個世界單位。

儲存後打開 scenes/frontier.tscn，按 F6 重開戰役，先建立營地，再往左走看新的防線位置。隨機樹木與寶箱區會一起留出牆外空間，不需逐一移動。

這個欄位控制每局開場的位置，不會讓遊戲中的現有城牆瞬移；未來的拓展玩法會透過居民施工完成。試完可以改回 -1100。桌面應用程式需重新打包才會更新。
