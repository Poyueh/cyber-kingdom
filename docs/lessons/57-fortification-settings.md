# 第 57 課：調整塔的威力與施工時間

在 Godot 的 FileSystem 點選 `data/campaign.tres`，到 Inspector 展開 **Fortifications**。

- **Building Seconds**：塔與新農地的施工時間，預設 3 秒。
- **Tower Damage**：箭的基礎傷害，預設 12；雷射是它的三倍。
- **Tower Range**：基礎射程，預設 460；每階再增加 40。

試著把 Tower Damage 改成 8，儲存後開新旅程。觀察塔上的每秒傷害圖示，再改回 12。舊旅程保存建立時的規則，因此用新旅程比較。

這些是 Resource 數值；畫面和建設流程不用一起修改。尚未收到本課練習回饋，暫不記為已掌握。
