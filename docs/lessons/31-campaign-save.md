# 第三十一課：調整自動存檔間隔

在 Godot 的檔案面板開啟 scenes/frontier.tscn，選最上層 Frontier 節點，在 Inspector 找到 Autosave Seconds。預設 5 秒；你可暫時改成 10 秒，再按 F6 執行這個場景。

投入一顆龍晶後按暫停，右上磁碟圖示表示儲存成功。停止遊戲再按 F6，應回到相同進度並保持暫停；按播放圖示繼續。暫停會立刻儲存，不受上述間隔限制，因此不必刻意等十秒才離開。

這裡調的是場景根節點的匯出屬性。存檔規則由內層處理，真正寫檔由外層處理，因此將來要改存檔位置或儲存方式，不必重寫居民和戰鬥。存檔檔案可從 Godot 的「專案 → 開啟使用者資料夾」查看，先保留原檔，別拿唯一進度做格式修改練習。

尚未收到你的練習結果，因此學習紀錄仍維持未驗證。
