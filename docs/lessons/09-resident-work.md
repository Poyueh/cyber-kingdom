# 第九課：調整工匠的作業時間

騎士現在只標記工作；工匠會自己走過去採集，再送回物資。今天只調整「到場後工作多久」，觀察它和走路、搬運的差別。

1. 在 Godot FileSystem 點 `data/frontier.tres`。
2. Inspector 展開 **Resident Expansion**，找到 **Work Seconds**，預設 6 秒。
3. 改成 4，F5 → REFUGE / 避難所。
4. 招攬居民，走到工坊花 2 廢料補充工程器具；居民自行領取成為工匠。
5. 到樹旁按 E 標記，觀察工匠：走路速度不變，開始作業後較快完成，仍須搬回聚落才增加木材。
6. 用同一地圖種子比較，試完可把 Work Seconds 還原 6。

同一區第一次送達物資後，清理地點會出現拓荒站。花 3 廢料下單，工匠建成後，附近物資可以就地入庫；這才會縮短搬運路程。**Outpost Seconds** 只改施工時間，和 Work Seconds 不同。

這些數值透過 Resource 注入規則，畫面動畫不決定收成，所以改動畫不會偷偷改變產量。新美術在 `data/frontier_art.tres`，目前先不用修改。

本輪仍不保存王國進度，重開／新地圖會重置。練習是否完成仍以你的回饋為準。
