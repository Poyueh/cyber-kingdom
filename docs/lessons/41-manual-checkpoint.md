# 第四十一課：手動與自動存檔

這次不改數值。在 Godot 開啟 scenes/frontier.tscn，按 F6 執行戰役。

1. 暫停，記住背包龍晶數，點音量面板底部的磁碟圖示建立手動檢查點。
2. 繼續遊玩，走遠並丟一顆龍晶，再暫停。自動存檔會保存這個新狀態。
3. 點面板底部的回轉箭頭讀取手動檢查點：角色與背包回到步驟 1。

手動槽不會被每五秒的自動存檔蓋掉；讀取後仍暫停，按播放圖示才繼續。

想知道 Godot 把存檔放在哪裡，可在編輯器的「專案」選單開啟使用者資料資料夾；user:// 是遊戲自己的可寫資料位置，與 FileSystem 面板裡的 res:// 專案素材不同。這次先觀察檔案，不需編輯或刪除。

此教材已提供，尚無使用者完成練習的回報，沒有更新掌握程度。
