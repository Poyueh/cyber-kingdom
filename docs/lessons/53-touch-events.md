# 第五十三課：快速手勢為何會漏掉

Godot 接收手指事件與更新遊戲規則，不一定發生在同一個時間點。舊版只看「手指還按著嗎」，很快下滑再放手，遊戲更新時就看不到付款動作。新版把一次下滑記住，交給下一次更新處理；按住多久則另行追蹤，因此快滑與長按都能運作。

小練習：開啟 scenes/frontier.tscn，選 HUD，在 Inspector 把 Control Mode 暫時改為 Touch，再按 F6。走到營火旁，滑鼠按住往下滑再立刻放開，應只填一格；下滑後按住，會繼續填完同一筆。測完把 Control Mode 恢復 Automatic。滑鼠只模擬一根手指，雙指操作仍需手機驗證。
