# 第五十一課：文字與玩法分開

Godot 的 TranslationServer 負責選取目前語言的文字；按鈕不需要為繁中、簡中、英文各做一份。遊戲的龍晶、背包與旅程資料也不因語言改變。

開啟專案並執行起始頁，在「跟隨系統／平台」選擇 English，再切回繁體中文。暫停時也可以操作；關閉再開會保留設定。

若想改按鈕措辭，在 localization/game_text.gd 搜尋「新遊戲」。每列第一欄是程式使用的鍵，後三欄是繁中、簡中、英文；先只改顯示欄位，再執行查看效果。包含 %d 或 %s 的字串要保留相同占位符，否則日數或旅程紀錄會顯示錯誤。

下一個小練習：把英文 New Game 改成 Start Journey，確認不影響既有旅程與另外兩種語言。練習前先另開 feature 分支。

尚未收到操作或理解回報，不把本課記為已掌握。
