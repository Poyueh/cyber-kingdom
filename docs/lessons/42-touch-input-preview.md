# 第四十二課：在 Godot 預覽手機操作介面

1. 開啟 scenes/frontier.tscn，選左側場景樹的 HUD。
2. 在 Inspector 找到 Control Mode。Automatic 依裝置選擇；Touch 可在電腦預覽手機按鈕，Desktop 隱藏觸控戰鬥按鈕。
3. 暫時選 Touch，儲存後按 F6，觀察左右方向、劍、跳躍與衝刺圖示。完成後改回 Automatic。

這只是預覽操作介面。滑鼠只有一個游標，不能因此證明同時兩指操作正常；真正多指需要裝置輸入。

程式使用同一組具名動作串接鍵盤和觸控。跳躍的體力規則仍在內層，HUD 只負責送出 jump 動作，因此調整按鈕外觀不必改戰鬥規則。

教材已提供，沒有使用者練習回報，不記為已掌握。
