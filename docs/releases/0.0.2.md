# Cyber Kingdom 0.0.2｜H5 遊戲內圖文指南

這次更新只適用 H5 網頁版。

- 暫停選單新增書本圖示，在遊戲內以 iframe 開啟圖文指南。
- 可捲動閱讀、切换操作平台與使用指南示意；閱讀時遊戲保持暫停。
- 右上角 × 或 Esc 關閉並回到暫停選單，再按播放繼續。
- 適配電腦、手機橫向與直向閱讀，遊戲存檔不因指南操作改變。

Windows／Mac 保持 [0.0.1 下載版](https://github.com/Poyueh/cyber-kingdom/releases/tag/v0.0.1)，本次沒有重建或替換桌面附件。
