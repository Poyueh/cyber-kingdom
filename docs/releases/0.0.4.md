# Cyber Kingdom v0.0.4 — 探索、巨龍終戰與更清楚的回饋

本次更新 H5 瀏覽器試玩版。

- 繁體中文、簡體中文、英文選單與語言偏好記憶。
- 荒地起步、較大探索地圖，居民自主巡遊與工作；兩側地獄之門封印後召喚巨龍，擊敗首領並清除殘敵才通關。
- 手機左右空白區可拖曳移動、下滑給龍晶，修復快速下滑放開遺失投入；保留攻擊／跳躍／衝刺按鍵。
- 場景連續接邊、探索霧與物件漸入、三頭身配角；劍術及義肢電容滿階後騎乘。
- 鬼魂提示放大，胜敗用大型王冠／骷髏區分；騎士倒下、敵人消散與居民失去職業的回饋更清楚。
- 森林、礦區與廢墟以高低、深度和疏密變化增加探索層次。

[線上試玩](https://poyueh.github.io/cyber-kingdom/)

原網址與同一瀏覽器的既有旅程可繼續使用；新旅程採新版較大地圖，舊紀錄保留原地圖。H5 存檔與本機預覽、桌面版分開。Windows／Mac 下載包維持 [v0.0.1](https://github.com/Poyueh/cyber-kingdom/releases/tag/v0.0.1)。

驗證：完整 tools/check.sh 通過，1302 行為 assertions、11 項新增勝敗場景 assertions 與全部既有檢查零失敗。H5 包經乾淨匯出、ZIP CRC／SHA256 和瀏覽器舊旅程載入驗證。

這仍是開發中的原型。iPhone 真機、完整旅程平衡與騎乘動作仍需後續驗收；騎乘死亡目前使用騎士倒下剪影。
