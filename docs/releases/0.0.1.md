# Cyber Kingdom 0.0.1

第一個公開試玩版本：人類靠龍晶驅動機械義肢，在魔法與巨龍統治的世界建立最後的避難所。

- 從營火起家，招募流浪者、提供器具，由居民採集、耕作、狩獵與建造。
- 探索隨機地圖，分配有限龍晶，擴建防線並抵禦逐日增強的兩側夜襲。
- 騎士三段連斬、跳躍、衝刺、體力與裝備強化；護送工匠封印兩端裂隙。
- 圖示介面、音量調整、自動與獨立手動存檔。
- Windows x64、macOS Apple Silicon／Intel，以及瀏覽器試玩版，附圖文玩家指南。

## 遊玩與下載

[線上試玩](https://poyueh.github.io/cyber-kingdom/) · [圖文指南](https://poyueh.github.io/cyber-kingdom/guide.html)

Windows 請完整解壓縮後啟動 .exe，保持 .pck 在同資料夾。Mac 解壓縮後啟動 .app。網頁 ZIP 是部署用檔案，遊戲需透過網址載入。

這是早期開發版本。Mac 尚未 Apple 公證，Windows 尚無商業程式碼簽章；其他電腦可能顯示安全提示。Windows 實機、iPhone Safari 效能與完整手感仍待驗收。瀏覽器存檔與桌面分開，清除網站資料會移除進度。

下載檔可用 SHA256SUMS.txt 核對完整性。Pages 會在 Release 發布後自動更新，部署完成前可能仍顯示舊內容。
