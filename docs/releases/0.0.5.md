# Cyber Kingdom v0.0.5 — 夜間施工與進化防線

本次僅更新 H5 瀏覽器試玩版。

- 平地探索與更長的新地圖；移除跳躍、瞬間衝刺與持劍守備兵，保留獵人／弓兵。
- 左右短拖慢走、長拖快跑並消耗體力；電腦以 Shift 加速。跑步拖劍、連斬踏進與騎乘攻擊回饋調整。
- 工匠夜間能在現存防線內施工；防線失守或施工沿途有敵人時撤回安全處。其他居民夜間分散走動。
- 守護塔升級為箭塔 → 連弩塔 → 雷射塔，有不同外觀、射速與實際傷害。
- 城牆升級為木牆 → 石牆 → 堡壘，耐久逐階提升；兵營升級強化所有弓兵。
- 開墾空地隨地圖種子決定城牆、守護塔或農地用途，投入龍晶後由工匠建造。農地需要農夫白天耕作。
- 拓荒站與新建築分開互動位置；繁中、簡中與英文圖文指南同步更新。

[線上試玩](https://poyueh.github.io/cyber-kingdom/)

同一網址、同一瀏覽器的舊旅程可以繼續。新旅程使用加長地圖，舊旅程保留原邊界；舊護民塔轉為第一階箭塔，原有防護次數、城牆損傷與修復投入保留。H5 存檔與本機預覽及桌面版分開。
