# Cyber Kingdom v0.0.6 — 長局效能

本次僅更新 H5 瀏覽器試玩版，沒有玩法或數值變動。專注在「玩久了越來越卡」。

- 畫面只繪製鏡頭看得到的部分。場景裝飾、採集點、動物、居民、掠奪者、區域名稱與地上龍晶都會裁掉畫面外的部分；世界比畫面寬好幾倍，先前整張地圖每幀都送出繪製指令。
- 地上未收的龍晶影響最大：一堆約七個繪製指令，而堆數沒有上限。裁剪後，後期營地的每幀繪製指令從 716 降到 342，全區域探索從 400 降到 257。
- 靜止在地面上的龍晶不再每幀重算落地物理，只保留計時與吸附判定。
- 自動存檔改為每 20 秒一次（原本 5 秒），暫停與局勢結束時仍然立即存檔。存檔前的自我驗證保留，但比對基準改成一局算一次重複使用，不再每次存檔重建整個世界。後期單次存檔成本從 11.6 ms 降到 10.9 ms，次數少四倍。

存檔格式沒有變動，同一網址、同一瀏覽器的舊旅程可以直接繼續。

[線上試玩](https://poyueh.github.io/cyber-kingdom/)

Windows／Mac 下載包維持 [v0.0.1](https://github.com/Poyueh/cyber-kingdom/releases/tag/v0.0.1)。

驗證：`tools/check.sh` 全綠，640 項通過、零失敗、無 SCRIPT ERROR；另通過架構、打包工具與三語檢查。繪圖裁剪以 27 張定點截圖比對，裁剪前後畫面位元組完全相同（涵蓋每個區域、世界左右邊界與 120 顆密集散佈的龍晶）。效能數字以 `tools/bench_sim.gd` 與 `tools/bench_draw.gd` 量測。

iPhone 實機、H5 實際瀏覽器長局試玩與後期大量建築的平衡仍待驗證。
