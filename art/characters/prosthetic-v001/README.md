# 龍晶義肢角色 v001
本輪以 art/concepts/kingdom-quality-v002/camp-study.png 為風格參考，使用內建 imagegen 製作四張角色原圖；未使用付費外部 API。完整提示和來源保存在 sources/generation.json，原圖均留存。

## 角色與動作
騎士維持紅披風與銀色中世紀鎧甲，以青綠髖部龍晶、機械前臂和金屬義肢腿統一造型。含待機、跑步、跳躍、衝刺與劈砍；左右朝向由既有呈現層鏡像。

居民包括流浪者、無職居民、農夫、獵人、守備兵及工匠，以服裝、器具與外露義肢辨識。工匠有走路、工作、搬運和待機四列；流浪者待機從新圖局部布料偏移製成，腳底保持不動。

## 重製
tools/prepare_prosthetic_art.py 使用已授權的 Pillow／NumPy 本機編修：
- 騎士及居民的生成圖含畫出的棋盤格，依邊界相連的淺灰色去背；工匠及攻擊圖保留原 alpha 並整理邊緣。
- 按實際空白帶切出居民各列，避免裁掉腳。以騎士龍晶核心及腳底對齊，其他角色共用身高尺度。
- 清除鄰格特效碎片，保留前方細長劍刃；少量越界劈砍光尾限制在既有畫格內。
- 騎士每格仍 128×96，腳底 y=80；居民每格 64×64、腳底 y=61。輸出尺寸及非空格檢查記在 atlas-report.json。
- 跑步原資源是八格，新原圖六個姿勢映射到八格，兩格有重複；跳躍四格中頂點共用原圖。這輪沒有宣稱每一格都是不同的新畫。
- 不覆寫任何原始 SpriteFrames、不改動畫速度或使用者自訂時長；使用既有 texture_overrides 換圖。後續仍需手工整理步態連貫與轉場。

## 遊戲裝配與驗證
scenes/frontier.tscn 指派騎士與流浪者圖集；data/refuge_art.tres 指派工匠和居民圖集。此版本先用於主戰役，訓練場角色與敵人仍使用原素材。

tools/preview_prosthetic.gd 在原生 Godot 場景用指定角色狀態檢查所有動作／職業，是美術展示配置，不是真人通關錄影。tools/preview_refuge.gd 另透過 HUD 訊號驗證原建造與招攬流程。手機實機、角色最終像素精修與效能尚未驗證。
