# 弧線連斬 v003

使用者回饋 v002 高舉直落的砍法缺乏美感。本版由內建 imagegen 重新繪製斜切、反手橫掃、踏步斜斬；手臂主要在胸腰之間出刀，身體有正面／側背轉動，劍路橫向與淺斜向交替，搭配細弧形殘光。造型參考 v002 第一格的紅披風、銀灰機械鎧及龍晶核心，沒有引用其他遊戲角色圖。

原始 4×6 圖、完整提示保留於 sources。實際三刀各八格；第二刀開頭共用首刀末格，第三刀開頭共用第二刀末格，以接續姿勢。步幅由動畫呈現，位移仍跟隨玩家操作。

- planted.png：8×3 格；每格 160×128。
- moving.png：8×24 格；各刀有八種連續步伐，共 192 格。
- 腳底 y=112；KnightVisual 覆蓋圖 offset=(0,-16)，接合原物理地面。
- recipe.json 保存選格、原圖裁切擴充、低位刀刃遮罩、被遮住的髖部錨點及刀光內的背景採樣點。
- 胸背轉向造成第 13／17 格核心被手部遮住；第 21 格的淺藍核心未通過飽和色門檻，改用經圖像確認的髖部座標，避免把頭盔眼部當成髖部。
- 清掉封閉刀弧內的棋盤背景，保留原細弧光；移動接合時保留刀刃、披風及身體前方的青色細弧。

重製方式：在專案根目錄以具有 Pillow、NumPy 的 Python 執行 `tools/prepare_combo_motion.py art/characters/combo-v003/recipe.json`。可提供第二個參數將輸出寫入另一個檢查目錄。腳本預設仍使用 v002 配方，且已確認重製 v002 的三張圖與原件逐位元相同。

新圖接入 data/knight_combo_motion.tres，使用既有動畫時間權重與戰鬥規則。只更換主戰役美術，沒有增加額外傷害或自動位移。手機實機與美感接受度仍待試玩。
