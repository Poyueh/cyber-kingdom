# 騎士劍術 v004

使用者認為站定連斬仍不好看。本版使用內建 imagegen 重繪 24 格原圖，造型參考本專案紅披風、銀色機械鎧與龍晶核心。三刀改為斜向拔切、反手回斬、跨步穿刺，增加直立／低重心對比、肩腰轉向與披風延遲。沒有引用外部遊戲角色素材，也沒有宣稱已達到成品美術品質或取得使用者認可。

- 原始生成圖：[sources/combo.png](sources/combo.png)。
- 完整實際生成提示：[sources/prompt.txt](sources/prompt.txt)。
- 遊戲使用圖集：[planted.png](planted.png)，8×3 格，每格 160×128。
- moving.png 保留既有呈現介面的相容版本；目前攻擊站定，不在遊戲中使用跑步腿。
- recipe.json 保存來源切格、髖部錨點、低劍刃、跨格刀光清理與封閉背景採樣。
- 主戰役接入 data/knight_combo_motion.tres，保留全部攻擊傷害、總時長與連斬踏步規則。

## 整理與銜接

生成圖雖要求真正透明背景，實際仍含棋盤格。依使用者既有本機處理授權，以 Python 清理連通背景、刀光內的封閉背景與相鄰格溢出的刀光，保留原圖。來源每列腳底並未落在等距網格，因此個別記錄裁切範圍，避免切掉靴子。低位披風邊緣有少量清理，沒有加入新角色或武器。

以髖部水平對齊與共同腳底 y=112 組合，各格有一致透明留邊。第二刀首格共用上一刀末格，第三刀同理；第一刀與第三刀結尾採第 23 張低劍中立姿勢，避免與既有待機銜接時突然將劍跳到背後。末段最後兩格停在同一中立姿勢，讓收勢穩定。

修改的是各格停留比例，沒有改整刀總時間。第一刀與終結刀的第 5 格仍從 40% 開始，第二刀第 4 格從 25% 開始，配合原有效揮擊窗口。前段蓄力較清楚，快速揮出後讓接觸姿勢稍久，收招回到中立。

## 重製

在專案根目錄，以含 Pillow／NumPy 的 Python 執行：

    python tools/prepare_combo_motion.py art/characters/combo-v004/recipe.json

可追加第二個參數指定檢查輸出目錄。流程增加可選來源裁切與清理遮罩，既有 v002／v003 配方不變；兩個舊版本的六張輸出已比對逐位元一致。

## 驗證

24 格透明度為 0／255，腳底一致，劍刃與角色不碰外框。原生 Godot 由 InputMap 驅動連斬並錄製，確認第一刀站定、後兩刀踏進、左右鏡像與畫面銜接。尚未做 iPhone／iPad 實機驗證；美感與手感仍需使用者試玩。
