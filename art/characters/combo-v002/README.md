# 獨立三段斬擊 v002

使用者回饋上一版動作仍不好看，這次重畫出刀姿勢。原圖由內建 imagegen 依 fluid-v001/attack.png 的騎士身分參考產生，完整提示在 sources/prompt.txt。原圖保留，沒有呼叫外部付費 API。

三段各八格：斜斬、獨立回挑、重劈。第三段起手複用第二段最後的高舉姿勢以對接，其他選格見 tools/prepare_combo_motion.py。回挑不倒播首刀，重劈有不同的背身蓄力、前壓與低位收勢。這是新的動作美術迭代，尚未經使用者確認成品品質。

tools/prepare_combo_motion.py 使用已授權的本機 Pillow／NumPy 去背、清掉跨格碎片、對齊腳底、量化共用 40 色，並按髖部標記組合跑步腿。低位劍刃以原圖劍柄／劍尖座標建立遮罩，披風保留紅色區域，避免把原地站姿的靴子帶進移動版。第一刀接觸格和重劈低位格原圖劍尖越界，擴充裁切再保留連通的騎士。

- planted.png：8 欄 × 3 列；每格 160×128。
- moving.png：8 欄 × 24 列；每段八種步伐，共 192 格。
- contact.png：人工檢視用，非執行時貼圖。
- 腳底 y=112、x 錨點 80；呈現節點 offset=(0,-16)，和原 KnightVisual 的 y=-32 合成後，腳底仍在物理地面。
- 全身貼圖與移動貼圖約 4.4 百萬像素，未壓縮 RGBA 約 17.6 MB；iOS 實機效能及整體記憶體仍待驗證。

data/knight_combo_motion.tres 提供三刀各自的畫格時間權重；固定出刀時長和命中窗口仍由 combatant 決定。主戰役關閉舊大型程序刀光，使用新劍刃本身的少量光邊及既有命中火花。訓練入口和未配置此資源的舊場景保留原呈現作為相容路徑。

目前處理腳本已改用 recipe.json 保存本版的切格／錨點／遮罩配方，預設無參數仍重製本版；可指定 v003 的配方產生橫掃版本。重構後已核對 planted、moving、contact 與本版提交檔逐位元相同。
