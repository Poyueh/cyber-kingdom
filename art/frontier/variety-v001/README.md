# Frontier scenery v001

Original image generated for Cyber Kingdom with the built-in image-generation tool on 2026-09-13. The visual reference was this project's `art/refuge/v001/tree.png`; no Kingdom artwork was copied. The exact prompt and untouched generated sheet are retained in `sources/`.

`tools/prepare_frontier_variety.py` cuts the sheet into twelve transparent sprites, removes the generated checkerboard (including enclosed branch gaps), and rescales with nearest-neighbor sampling. Local processing is authorized by the project owner. The source sheet is a production input and is excluded from release packages by the existing export rules.

Four tree silhouettes and two mineral silhouettes decorate actual harvestable resources. Logs, ferns, mushrooms, broken arches, dragon statues and mechanical debris are cosmetic biome scenery. Placement uses an independent deterministic seed stream and does not change resource yields, collision or save data. These are prototype assets; further art direction and small-scale phone readability remain subject to player review.
